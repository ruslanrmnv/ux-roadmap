# UX: от нуля до найма

Мини-приложение-трекер пути в UX: экран «Сейчас» с одной текущей задачей и мини-шагами, карта этапов с гейтами, встроенная база знаний (короткие уроки теории с проверочными вопросами, словарь терминов, встроенный видеоплеер с подобранными роликами и обучающие тренажёры — карточки, пары, спринт-квиз и детектив по эвристикам), стрик с напоминаниями (уведомления браузера или событие в календаре) и статистика. Весь сайт — один файл `index.html`, прогресс хранится в localStorage браузера.

## Как включить GitHub Pages

1. Откройте в этом репозитории **Settings → Pages**.
2. В блоке **Build and deployment** выберите **Deploy from a branch**, укажите ветку **main** и папку **/ (root)**, нажмите **Save**.
3. Подождите минуту-две и обновите страницу **Settings → Pages** — сверху появится ссылка вида `https://<ваш-логин>.github.io/<имя-репозитория>/`. Это и есть адрес сайта.
